Privacy Policy

Last updated: 18 October 2026

"Next Token Uploader" is a personal tool used only by the owner of the Next Token YouTube channel to upload videos they made to their own channel. It is not offered to the public.

What the app accesses

With the owner's permission, the app uses Google's YouTube Data API with the youtube.upload permission, solely to upload videos and set their title, description and tags on the owner's channel.

What is stored

The Google sign-in token is stored only on the owner's own computer, so uploads can run automatically. No data is sent to, sold to, or shared with anyone else, and no information about viewers is collected.

Removing access

Access can be revoked at any time from Google Account → Third-party access.

Google API Services

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
